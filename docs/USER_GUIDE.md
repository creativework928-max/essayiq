# User Guide

1. Start the FastAPI backend.
2. Start the frontend.
3. Paste an essay or load the clearly labeled synthetic demo essay.
4. Select **Analyze Essay**.
5. Review the holistic score if a trained model is loaded.
6. Review analytical indicators and writing statistics.
7. Review strengths and areas to review.
8. Treat the result as an aid to review, not a definitive human grade.
